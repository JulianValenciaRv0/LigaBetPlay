# Sistema de Gestión Liga BetPlay
Este proyecto consiste en el desarrollo de un sistema de gestión para una liga de fútbol, realizado en Python utilizando estructuras de datos como diccionarios, listas, ciclos y funciones.
El objetivo principal del programa es permitir la administración básica de equipos, jugadores, partidos y estadísticas de una liga deportiva desde consola.

## Funcionalidades del sistema
El sistema cuenta con los siguientes módulos:

### 1. Registro de equipos
Permite registrar equipos mediante un código único y almacenar información general del club junto con sus estadísticas iniciales.

### 2. Registro de planta técnica
Permite asignar la planta técnica correspondiente a cada equipo, incluyendo:
- Director técnico
- Preparador físico
- Preparador de arqueros
- Médico
- Fisioterapeuta

### 3. Registro de jugadores
Permite registrar múltiples jugadores por equipo almacenando información como:
- Nombre
- Nacionalidad
- Posición de juego
- Número de dorsal
- Edad

### 4. Programación de fechas
Permite programar partidos por fecha, registrando:
- Equipos participantes
- Identificador del partido
- Marcador inicial

### 5. Registro de estadísticas
Permite registrar los marcadores de cada partido y actualizar automáticamente las estadísticas de los equipos:
- Partidos jugados
- Partidos ganados
- Partidos perdidos
- Partidos empatados
- Goles a favor
- Goles en contra
- Total de puntos

### 6. Consulta de información
El sistema permite visualizar información registrada mediante un menú de búsqueda:

# 6.1 Listar planta técnica
Muestra la planta técnica de un equipo seleccionado.

# 6.2 Listar jugadores
Muestra los jugadores registrados de un equipo.

# 6.3 Visualizar estadísticas
Muestra las estadísticas actuales de un equipo.

# 6.4 Regresar
Retorna al menú principal.
